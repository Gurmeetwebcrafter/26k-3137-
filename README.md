## Project Description

This project provides an introduction to computers, their different

## Introduction to Computers

A computer is an electronic device that accepts data as input,
processes it, stores information, and produces output.

## Types of Computers

Computers can be classified into different types:

- Supercomputers
- Mainframe computers
- Minicomputers
- Microcomputers

### Examples

| Type | Example | Main Use |
|---|---|---|
| Supercomputer | Frontier | Scientific research |
| Mainframe | IBM zSeries | Large-scale processing |
| Microcomputer | Laptop | Personal use |
